# Cross-Board Job Radar (Public Code)

Privacy-first public code repository for the Cross-Board Job Radar. Production preferences, resume-derived profile, job history, and evaluation reports belong in a separate private repository.

**Not yet configured for production.** The active original private Job Radar remains unchanged. Public scheduled scans and notifications must remain disabled until the independent data store is initialized, GitHub Secrets are verified, and the cutover is explicitly approved.
